# bisphenols_maternalcare_epigenome
R Code used for the manuscript "Postnatal maternal care normalizes the hypothalamic DNA methylome following prenatal bisphenol exposure"

Supplementary Table S17 (Laubyetal_Supplementary_Table17.xlsx) displays all the code files and data files used for the bioinformatic analyses, as well as the information from all samples used for analyses.
